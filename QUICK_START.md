# Быстрый старт upwork-scout (Windows)

Подробности — в [README_RU.md](README_RU.md).

## Что нужно заранее

- Python 3.11+ (проверено на 3.14);
- установленный Google Chrome;
- аккаунт Upwork с сохранёнными поисками;
- ключ OpenRouter — не обязателен: без него отбор идёт только по правилам.

## 1. Перейти в папку проекта

```
cd D:\1PythonProjects\20260924upwork\upworksearch
```

## 2. Создать и активировать виртуальное окружение

```
python -m venv .venv
.venv\Scripts\activate
```

В Git Bash активация: `source .venv/Scripts/activate`.

## 3. Установить зависимости

```
pip install -r requirements.txt
```

Команду `playwright install` запускать **не нужно**: скрипт использует ваш установленный Chrome.

## 4. Настроить `.env` (необязательно, только для AI-оценки)

Если `.env` ещё нет, создайте его из шаблона:

```
copy .env.example .env
```

Впишите ключ со страницы https://openrouter.ai/settings/keys:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

Если ключ уже задан в переменной окружения Windows `OPENROUTER_API_KEY`, поле в `.env` можно оставить пустым.

## 5. Первый запуск и вход в Upwork

В PowerShell перед именем файла из текущей папки нужен `.\`. В cmd можно писать просто `run.bat`.

```
.\run.bat
```

1. Откроется отдельное окно Chrome с профилем `browser-profile/`: это не ваш обычный профиль.
2. Войдите в Upwork вручную. Если Upwork покажет проверку, пройдите её сами. Скрипт ждёт до 10 минут.
3. После входа скрипт сам найдёт все сохранённые поиски, пройдёт их по очереди и закроет окно.

При следующих запусках вход уже не нужен: сессия хранится в `browser-profile/`.

## 6. Открыть отчёт

Путь к отчёту печатается в конце запуска:

```
outputs\upwork-report-ГГГГ-ММ-ДД-ЧЧ-мм.html
```

Проверьте в отчёте:

- число поисков совпадает с сохранёнными в Upwork;
- в карточках заполнены бюджет, отклики и данные клиента;
- если где-то 0 карточек — поставьте `collection.debug_dump_html: true` в `config.yaml`, запустите снова и посмотрите папку `debug\`.

## 7. Проверить, что тесты проходят

```
.venv\Scripts\python -m pytest -q
```

Ожидается: `249 passed`.

## Полезные команды

| Команда | Что делает |
|---|---|
| `.\run.bat` | обычный запуск: только новые вакансии |
| `.\run.bat --show-all` | показать все найденные вакансии |
| `.\run.bat --no-ai` | без AI-оценки |
| `.\run.bat --no-details` | не открывать страницы вакансий (быстрее) |
| `.\run.bat --load-more 2` | нажимать «Load More Jobs» по 2 раза в каждом поиске |
| `.\run.bat --rescore` | пересчитать оценки по `config.yaml` без браузера |
| `.\run.bat --login-only` | только войти в Upwork, без сбора |

Веса, пороги и стоп-слова настраиваются в `config.yaml`. После правок запустите `.\run.bat --rescore`, чтобы увидеть эффект без повторного прохода по Upwork.
